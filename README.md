Thynkr – ACE6173 Assignment
Thynkr is an Android note‑taking application built for the ACE6173 course assignment by team YoungBucks. It lets users create and organize notes with Firebase‑backed authentication and storage.

Features
- User registration, login, and logout with Firebase Authentication.
- Forgot‑password flow via email.
- Create, edit, and delete notes.
- Organize notes into categories.
- Settings page for font size preferences.
- Admin screen to view/manage users.

Technologies
- Android Studio 
- Programming language: Java
- Firebase Authentication
- Firebase Firestore for notes data

How to Run
1. Clone this repository:
   - `git clone <repo-url>`
2. Open the project in Android Studio.
3. In the Firebase console, create a project and enable Email/Password auth.
4. Download your `google-services.json` and place it in the `app/` folder.  
5. Sync Gradle, then run the app on an emulator or Android device.'
